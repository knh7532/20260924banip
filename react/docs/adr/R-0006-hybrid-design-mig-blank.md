# ADR R-0006: 하이브리드 디자인 소스 + MIG 소비 + 공란 정책 (Phase R7)

- 상태: Accepted (인간 지시·결정, 2026-07-17)
- 날짜: 2026-07-17

## 컨텍스트

인간 지시 4건: ① 처음의 정적 수치를 지우고 공란으로, ② 본문(대시보드) 디자인·카드
배치는 형제 프로젝트(Grafana판)와 유사하게, ③ 좌측 사이드바는 PPTX와 유사하게,
④ 실환경이 **서버당 H200 4장 × MIG 2분할(3g.71gb)** 이고 SQream이 MIG 인스턴스
단위로 실행됨을 반영. ④는 계약 TV-C1 v2.0(형제 프로젝트 소유)으로 개정되었다.

## 결정

1. **디자인 소스 이원화**: 본문 = Grafana판(`gen_dashboard.py`/실화면) 미러, 사이드바 =
   PPTX. R-0005의 "PPTX 단일 기준"을 본문에 한해 대체한다.
   - 시계열: 단일 패널(4서브차트) → **독립 카드 4개**(제목 "GPU사용률(%)" 등 Grafana
     표기, 접미사 없음). 슬림 공유 범례는 유지(Grafana는 범례 숨김 — 8선 판별을 위한
     의도적 편차).
   - 게이지: R6의 fullCircle 링 → **arc(반원, c3 기본형)** 회귀. 임계 규칙 유지,
     전력 max 1600→**2800W**(H200 TDP 700 × 4).
   - "시간 구간"을 상세 패널에서 **독립 소패널**로 분리(Grafana text 패널 대응).
   - 필터바에 Grafana 리셋 링크 2종 미러("전체 구간(30분)으로 리셋" = 시간범위+브러시만,
     "구간·필터 모두 초기화" = 전체 초기화).
   - 그리드 비율: `.grid` 1.18fr(13:11), `.lower` 3fr(18:6) — Grafana 24컬럼 환산.
2. **사이드바 = PPTX 계층**: "GPU 모니터링"(활성) 아래 화면 5종을 **들여쓴 sub 항목**
   으로. aria 규칙(R-0005)은 유지.
3. **MIG 소비** (계약 v2.0):
   - 시리즈/타임라인 행 키 = `node/gpu/mig`(24슬롯). 라벨: 단일 "GPU-0·M0" /
     복수 "S01·GPU0·M0"(시계열), "S01·G0M0"(타임라인 행 — 92px 마진 제약).
   - **색은 물리 gpu 공유**(4색 토큰 재사용, MIG 쌍은 라벨로 구분) — 8색 확장 대비
     시각 잡음이 적고 토큰 SoT 불변.
   - **MIG 필터는 노출하지 않음**(Grafana판엔 있으나 React 필터바는 3개 유지 — 과밀
     방지. 계약상 mig 매처는 선택 사항이라 무필터 소비가 유효).
   - 사이드바 사용량 분모 = MIG 슬롯(8), 카드 부제 "4 GPU · 8 MIG"(`gpuPhysical`용
     count(count by(gpu)) 쿼리 추가). 상세 "GPU" 항목 → "활성 MIG".
   - 타임라인 행높이 임계 4→**8행**(단일 서버 = 8 MIG): ≤8행 30px / 초과 20px.
4. **공란 정책** (인간 확정 "둘 다"):
   - 연결 끊김(연속 실패 `DISCONNECT_THRESHOLD=3`, 배너와 동일 기준) 시 세 데이터
     훅이 데이터를 EMPTY/null로 **리셋** — 마지막 값(stale)이 화면에 남지 않는다.
     재연결 시 다음 성공 tick이 자연 복원.
   - RangeDetail의 null 문구는 `disconnected`에 따라 "연결 끊김 — 데이터 없음"으로 분기.
   - Prometheus에 남은 구(v1.x·정적) 히스토리는 **볼륨 초기화**로 1회 정리(운영 절차,
     Phase D — grafana-data는 보존).

## 결과

- PromQL은 by-list 3곳에 `mig` 추가 외 불변 — queries.contract가 v2.0 문서와 자동 대사.
- 테스트 223 passed(+α)·verify(커버리지 perFile 80/80/70)·build 통과.
- R-0005의 "(선택 인스턴스: …)" 제목 접미사는 테이블·타임라인에 유지(시계열 카드는
  Grafana 표기라 제외).

# ADR R-0003: 원본 시안 100% 재현 (사이드바 포함)

- 상태: Accepted
- 날짜: 2026-07-15

## 컨텍스트

형제 프로젝트는 "순수 Grafana" 결정 때문에 원본 시안의 **좌측 사이드바(AX Portal 메뉴 + GPU 서버 목록 카드)** 를 재현하지 못하고 생략했다. React는 이 제약이 없다.

## 결정

원본 시안의 **모든 구성요소를 재현**한다:
- 좌측 사이드바 — 로고, 메뉴(개요 / **GPU 모니터링**(활성) / 인스턴스별 GPU / GPU 상세 / 프로세스 모니터링 / LLM 모니터링 / Cost 분석 / 알림 / 대시보드 설정), **GPU 서버 목록 카드 3개**(서버명 · "정상" 배지 · "4 / 4 GPU 사용 중")
- 본문 — 헤더(제목·현재 시각), 필터바 5종, 테이블 2종, 타임라인 + 범례, 선택 구간 상세, 시계열 4종, 서버 카드 3종
- 색·타이포·레이아웃 비율은 `docs/design-tokens.md`(시안 추출값)를 따른다

사이드바 메뉴 중 **현재 화면(GPU 모니터링)만 활성**이고 나머지는 표시하되 비활성(클릭 무반응)이다 — 타 화면 구현은 범위 밖(AGENTS.md §0.1 Out of Scope).

## 대안

- **본문만 구현(사이드바 생략)**: 형제 프로젝트와 동일 범위. 인간이 전체 재현을 선택하여 기각.
- **사이드바 메뉴를 실제 라우팅으로 구현**: 타 화면(개요·프로세스·LLM·Cost)이 정의되지 않았고 데이터도 없다. 범위 밖으로 기각.

## 결과

- 서버 목록 카드의 "정상" 배지와 "4/4 GPU 사용 중"은 **실제 메트릭에서 산출**한다(예: 서버별 타깃 생존·타임라인 상태 기반) — 하드코딩하지 않는다. 산출 규칙은 구현 단계에서 계약 범위 내 메트릭으로 정의한다.
- 사이드바가 화면 폭 12.4%를 차지하므로 본문 그리드는 87.6% 기준으로 배치한다.
- 비활성 메뉴는 `aria-disabled`로 표시해 접근성 도구가 오해하지 않도록 한다.

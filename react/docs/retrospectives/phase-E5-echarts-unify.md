## 잘된 점

- **시안 → 승인 → 교체** 를 차트 단위로 반복하니 되돌림이 한 번(X-View, 절차 정정)으로 끝났고, 승인마다 커밋이 잘려 리뷰 diff 가 읽힌다.
- 옵션 빌더를 순수 함수로 두고 `renderItem` 까지 api 없이 호출 가능하게 만들어, canvas 인데도 "무엇을 그리나"를 단위 테스트로 잠갔다(타임라인 16건·X-View 11건·브러시 4건).
- 픽셀 재현을 감(느낌)이 아니라 **공식**으로 했다 — scaleBand·tickStep·viewBox meet 를 코드로 옮기고 캡처로 검증.
- 브러시 시안에서 미니맵이 260px 상자에 잘려 보이지 않던 **기존 문제**를 발견해 함께 고쳤다.

## 어려웠던 점

- **지연 마운트 함정**: 데이터가 늦게 오는 컴포넌트가 첫 렌더에서 null 을 반환하면 `useEchart` 의 마운트 1회 init 이 ref 없이 지나가 영영 만들어지지 않는다 — 브러시에서 실사고(드릴다운 캔버스 없음). 내부 컴포넌트 분리로 해결하고 ADR 에 규칙으로 올렸다.
- **초기 높이 0**: 타임라인 호스트는 마운트 직후 높이가 0 이라 `useEchart` 실측이 비어 오고 ResizeObserver 도 늦는다 — 폭을 호스트에서 직접 읽어 명시 resize.
- **CDP 드래그는 브러시를 못 만든다**: `left_click_drag` 가 중간 mousemove 없이 down/up 만 쏘아 zrender 브러시가 시작되지 않았다(d3 도 동일). 합성 이벤트(중간 move 포함)로 확인.
- **외부 사용자에게 화면 보이기**: 로컬 브라우저 스크린샷은 파일로 남지 않아 헤드리스 크롬 `--screenshot` + PIL 크롭으로 전달 파이프를 만들었다. 시안 상태 프리셋(`?labzoom`·`?labrows`)이 필요했다.
- **셸 heredoc 깨짐**: 백틱이 든 한국어 주석을 heredoc 파이썬으로 넘기면 Bash 파서가 `''` 매칭 오류를 냈다 — 스크립트를 파일로 저장해 실행하는 방식으로 우회.

## 다음에 다르게 할 것

- 지연 마운트 컴포넌트는 처음부터 "데이터 있을 때 마운트되는 내부 컴포넌트" 패턴으로 시작한다.
- 시안 페이지에 URL 프리셋을 처음부터 넣어 헤드리스 캡처를 자동화한다.
- 승인 질의는 **캡처 전달 뒤**에만 한다(사용자가 화면을 못 보는 상황을 먼저 확인).

# ADR-0004: 전 리스너 0.0.0.0 바인딩 (다중 PC 연결 대비)

- 상태: Accepted
- 날짜: 2026-07-14

## 컨텍스트

상위 `../mockup/` 프로젝트는 codex 리뷰 지적(CDX-0.4-03)에 따라 모든 리스너를 127.0.0.1 전용으로 바인딩했다. 이 목업은 인간 지시로 **다른 컴퓨터에서 브라우저/Prometheus로 접속하는 시나리오**를 전제한다 (2026-07-14 계획 검토 시 명시 지시).

## 결정

exporter(9801)/Prometheus(9091)/Grafana(3001) 전 리스너를 **0.0.0.0으로 바인딩**한다. docker-compose 포트 매핑에 IP 접두사를 붙이지 않고, exporter의 `LISTEN_ADDR` 기본값과 네이티브 모드 스크립트도 동일하게 한다.

보완 통제:
- Grafana 익명 접근 금지 유지(`GF_AUTH_ANONYMOUS_ENABLED=false`) + `.env` 자격증명(템플릿 `.env.example`의 비밀번호는 **의도적으로 빈 값** — compose `${VAR:?}`·native 스크립트가 빈 값이면 기동 거부하므로 사용자가 반드시 설정해야 함. 실값은 커밋 금지)
- 사설망(폐쇄망/사내망) 사용 전제 — README에 명시
- Windows 방화벽 인바운드 규칙(9801/9091/3001)은 사용자가 필요 시 직접 허용 — README에 안내
- Prometheus/exporter는 자체 인증이 없으므로 신뢰 네트워크 밖 노출 금지 — README에 경고

## 대안

- **127.0.0.1 유지 + SSH 터널/리버스 프록시**: 접속 절차가 복잡해져 시연 목적에 부적합. 기각.
- **특정 인터페이스 IP 바인딩**: 장비/네트워크 변경 시마다 재설정 필요. 기각.

## 결과

- 상위 mockup의 127.0.0.1 관습에서 **의도적으로 이탈**한다. 두 프로젝트의 보안 전제가 다름을 문서로 남긴다(이 ADR).
- 바인딩 범위 변경(축소 포함)·인증 완화는 AGENTS.md §4-6 이스케이프 대상이다.

# ADR R-0005: 인스턴스 중심 뷰 — PPTX 디자인 재정렬 (Phase R6)

- 상태: Accepted (인간 지시·결정, 2026-07-17)
- 날짜: 2026-07-17

## 컨텍스트

인간 지적: ① 화면 디자인이 PPTX 취지와 다르고, ② 형제 프로젝트의 동적 시뮬레이션
패턴이 화면에서 읽히지 않는다. PPTX를 COM 렌더로 대조한 결과, PPTX의 핵심 취지는
**"선택 인스턴스" 중심 화면**이었다 — 4개 패널 제목에 "(선택 인스턴스: GPU-Server-01)",
타임라인은 그 서버의 GPU-0~3 4행에 쿼리명 라벨, 시계열은 4선 + 하단 GPU-0~3 범례,
서버 카드는 원형 링 게이지 4단 스택. 데이터 계층은 이미 완전 라이브(PromQL 불변)라
시각 계층만 재정렬했다.

## 결정 (인간 확정 사항 포함)

1. **기본 화면은 All 유지** (인간 결정) — 첫 화면은 12 GPU composite. 사이드바 서버
   카드(버튼, `aria-pressed`)를 클릭하면 그 서버 단독 선택으로 전환(재클릭 시 All 토글,
   GPU 선택은 리셋). `DEFAULT_STATE`·URL 코덱은 변경하지 않는다.
2. **패널 제목 접미사**: 0개 "(인스턴스: All)" / 1개 "(선택 인스턴스: GPU-Server-0N)" /
   ≥2개 "(인스턴스: N개 선택)" — 2개 선택을 "All"로 뭉개면 사실과 다르다.
3. **타임라인**: 단일 인스턴스면 행 라벨 "GPU-0"(PPTX 표기), 아니면 기존 "S01·GPU0".
   행 수 ≤4면 행 높이 34px(PPTX의 굵은 막대), 아니면 24px. 세그먼트 폭이 허용하면
   **쿼리명 라벨**을 막대 위에 그린다(`fitLabel` — 문자폭 추정, jsdom에 측정 API 없음).
   라벨은 **쿼리명만** — "(type)" 접미사는 DES-1(계약-시안 유형 스왑)을 텍스트로도
   드러내므로 넣지 않는다. 색은 **계약 query_type 기준 유지**(인간 결정 — DES-1 오픈).
4. **시계열**: 제목 "인스턴스별 GPU 시계열", c3 인셋 범례 제거 → **하단 공유 HTML
   범례**(단일 인스턴스면 정확히 GPU-0~3). c3 범례 호버 하이라이트 상실은 수용
   (Grafana 재현판도 범례 숨김). "전력 (W)" → "전력사용량 (W)".
5. **서버 카드 링 게이지**: c3 `gauge.fullCircle` + 4단 세로 스택 + "N GPU" 부제.
   임계는 Grafana 재현판 기준 — %: green→orange(70)→red(85), 온도: 75/85, 전력:
   단색(info) **max 1600W**(기존 2000W에서 보정). `color.threshold`는 `unit:"value"`
   필수(생략 시 max 대비 %로 오독). 링 잔여부는 `--panel-alt`로 다크 보정.
6. **RangeDetail**: PPTX의 × 닫기 버튼 재현 — Panel `actions` 슬롯에 상시 렌더,
   선택 없으면 disabled.
7. **레이아웃 비율 보정**: `.grid` 1.26fr:1fr (PPTX 47.2:37.4), `.lower`
   minmax(0,3.16fr):minmax(0,1fr) (PPTX 64.7:20.5).
8. **사이드바 메뉴 연동**: 단일 인스턴스 뷰에서 "인스턴스별 GPU" 항목을 시각 강조
   (`sidebar__item--linked`) — 단 `aria-current="page"`는 실제 현재 화면(GPU 모니터링)
   에만 남긴다(스크린리더 의미론 유지, ADR R-0003 부분 보완).

## PPTX 해석 판단

- **PPTX 내부 모순**: 필터바는 "인스턴스(서버) All"인데 패널 제목은 "선택 인스턴스:
  GPU-Server-01" — 필터 상태가 화면 전체를 구동하는 것으로 해석해 해소했다(제목
  접미사는 필터에서 파생).
- **PPTX 스냅샷 색상 주의**: 시안의 메모리 68% 게이지가 주황으로 칠해져 있으나
  임계 규칙(70 미만 green)과 모순 — 시안은 시점 값의 그림일 뿐, **임계 규칙이 우선**.
- 시간 범위 기본은 PPTX "Last 6 hours"가 아닌 30분 유지(DES-2 시간 압축, 기승인).

## 결과

- 동적 시뮬레이션이 화면에서 읽힌다: 세그먼트 라벨로 쿼리 생성/소멸이 보이고,
  In Queue 배지·링 게이지 임계 전환·시계열 부하 상관이 시각화된다.
- HCI-R4-1(픽셀 충실도 인간 검토)은 본 작업의 PPTX 나란히 대조로 종결. HCI-R4-4
  (DES-1 색 스왑)는 인간 결정으로 **계약 기준 유지** — 항목 종결.
- 도달 불가 방어 가드(ref/effect 순서)는 `/* v8 ignore next */`로 주석 처리해
  커버리지 임계(perFile 80/80/70)를 정직하게 유지한다.
